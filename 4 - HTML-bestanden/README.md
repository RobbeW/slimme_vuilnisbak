# Slimme Vuilnisbak - HTML-bestanden

Deze map bevat de directe webmap van het project. De canonieke GitHub Pages-pagina's staan in de root van de repository.

- `index.html` is de directe webmap-landingspagina.
- `platform.html` is het directe webmap-platform.
- `style.css` bevat de gedeelde visuele stijl.
- `sketch.js` bevat camera, AI-model, demomodus, WebSerial en rapportage.
- `landing.js` bevat de kleine navigatie-interactie van de landingspagina.
- `image_model/` bevat het standaard Teachable Machine model.

## Lokaal starten

Start deze map via een lokale server:

```bash
python -m http.server 8000
```

Open daarna `http://localhost:8000/`.

Voor WebSerial gebruik je Chrome of Edge via `https://`, GitHub Pages of `http://localhost`.
