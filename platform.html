Wat doet het AI-model?

Het model vergelijkt het camerabeeld met voorbeelden uit de training. Per klasse berekent het een zekerheid. De hoogste zekerheid wordt de voorspelling.

De browser stuurt pas een code wanneer de voorspelling stabiel genoeg is. Zo reageert de microcontroller minder snel op losse foutjes.

Klasse naar code

De code wordt naar de Arduino of micro:bit gestuurd. Gebruik dezelfde codes in je microcontrollerprogramma.

Wat zie je op het platform?

Klasse
Het label dat het model aan een beeld koppelt, zoals PLASTIC of PAPIER.
Zekerheid
Hoe sterk het model denkt dat een klasse past bij het beeld. 100% is heel zeker, maar niet automatisch juist.
Code
Het teken dat naar de microcontroller gaat. Die code bepaalt welke LED, servo of sorteeractie reageert.
Foute voorspelling
Dat is leermateriaal: kijk welke voorbeelden ontbreken of te veel op elkaar lijken.
